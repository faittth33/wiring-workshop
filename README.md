# 接线工坊 · Wiring Workshop

四套电工实操接线交互练习。纯静态网页，无需登录，不依赖后端或外部 API。

**在线练习：** https://faittth33.github.io/wiring-workshop/

**源码仓库：** https://github.com/faittth33/wiring-workshop

## 四套课程

| 课程 | 内容 | 完整参考导线 |
| --- | --- | --- |
| K2-1 | 点动与连续运行 | 25 根 |
| K2-2 | 接触器互锁正反转 | 35 根 |
| K2-3 | 照明与插座电路 | 17 根 |
| K2-4 | 连续运行与电流测量 | 25 根 |

## 使用

1. 默认空白接线板，先选择导线颜色，再依次点击两个端子。
2. 点击“完整参考接线”显示全部正确线路，点击导线可高亮其两端。
3. 点击“清空练习”回到空板；支持下一根提示、撤销、拆线和原理图。
4. 接线检查通过后才能合闸。按下并松开按钮，观察自锁、停止和保护动作。

支持电脑与手机布局、键盘接线选择框、深浅主题和 JSON 进度导入导出。
各课程进度独立保存在浏览器 localStorage，恢复进度默认断电。清理浏览器数据或更换网页地址会影响保存；请用“导出进度”备份。模拟运行状态不持久保存。

## 本地运行

下载仓库后，用新版 Edge 或 Chrome 打开 `index.html`，保持网页文件的目录结构。

也可以启动静态服务器：

```sh
python -m http.server 8765
```

访问 http://localhost:8765 。

## 修改源码

- `index.html`：网页入口与操作说明。
- `styles.css`：外层界面；`app.js`：课程导航、保存和导入导出。
- `circuits/*.html`：四套课程的交互与电路模型。
- `courses.json`：课程信息；`circuit-base.css`：共用样式。
- `circuits.js`：供网页直接加载的生成文件。

修改课程模块或共用样式后，运行以下命令并提交更新后的 `circuits.js`：

```sh
node tools/build.mjs
```

已附带生成文件，日常使用无需安装 Node.js 或依赖。
